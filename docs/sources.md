## 2. Product roles (FAMILY_PRODUCTS in `src/ahg/cve.py`)

**Role vocabulary:**
- `server`: the page states the product is a server or daemon.
- `multi`: the page states it is several of server, client and library.
- `unstated`: the page was opened but does not state a role.
- `UNAVAILABLE`: no page could be opened.
